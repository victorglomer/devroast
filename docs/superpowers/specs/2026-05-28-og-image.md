# Spec: OG Image — Imagens Open Graph para Resultados de Roast

## Resumo

Gerar imagens Open Graph (og:image) automáticas para os links compartilháveis dos resultados de roast, usando Takumi (`takumi-js`) para renderização server-side das imagens, seguindo o design do frame "Screen 4 - OG Image" do arquivo Pencil.

## Decisão

**Abordagem: Takumi ImageResponse + API Route.** Usar `takumi-js` com `ImageResponse` (API compatível com `next/og`) em um route handler do App Router. O Takumi renderiza JSX em PNG sem headless browser, com suporte a Tailwind v4 e fontes variáveis. A fonte Geist já vem embutida no `@takumi-rs/core` (napi-rs). JetBrains Mono é carregada via `fetch()` do Google Fonts.

## Design — Frame "Screen 4 - OG Image" (Pencil)

- **Dimensões:** 1200×630px (padrão OG)
- **Background:** `#0A0A0A` (`$bg-page`)
- **Padding:** 64px em todos os lados
- **Layout:** vertical, gap 28px, centralizado

### Elementos (top-down)

1. **Logo row:** `>` (verde `#10B981`, JetBrains Mono 24px bold) + `devroast` (branco `#FAFAFA`, 20px medium)
2. **Score:** valor (ex: `3.5`, âmbar `#F59E0B`, JetBrains Mono 160px weight 900) + `/10` (cinza `#4B5563`, 56px)
3. **Verdict:** dot 12px + texto (ex: `needs_serious_help`, 20px). Cor dinâmica conforme score: `< 4` = vermelho `#EF4444`, `< 7` = âmbar `#F59E0B`, `>= 7` = verde `#10B981`
4. **Meta:** `lang: javascript · 7 lines` (cinza `#4B5563`, 16px JetBrains Mono)
5. **Quote:** roast title (branco `#FAFAFA`, 22px Geist, line-height 1.5, centralizado)

### Arquivos novos

| `src/components/og-image.tsx` | Componente React da OG Image (1200×630, inline styles) |

### Arquivos modificados

| Arquivo | Descrição |
|---------|-----------|
| `next.config.ts` | Adicionar `@takumi-rs/core` a `serverExternalPackages` |
| `src/app/results/[id]/page.tsx` | Adicionar `generateMetadata` com `og:image` apontando para `/api/og?submissionId={id}` |

### Fluxo

```
Share link (ex: /results/abc-123)
  → Crawler/App lê metatags
    → generateMetadata gera og:image = /api/og?submissionId=abc-123
      → Route handler GET /api/og
        → getSubmissionWithRoast(submissionId)
        → fetch JetBrains Mono WOFF2 do Google Fonts
        → render <OgImage /> com ImageResponse (Takumi)
        → return PNG 1200×630
```

### Componente OG (`og-image.tsx`)

Componente React puro com inline styles (sem Tailwind, para isolamento). Props tipadas:

```typescript
interface OgImageProps {
  score: number;
  verdict: string;
  roastTitle: string;
  language: string;
  lineCount: number;
}
```

Estrutura do componente espelha o design do Pencil: container 1200×630 com fundo escuro, padding 64px, flex column centrado, com os 5 elementos descritos acima.

### Fontes

| Fonte | Origem |
|-------|--------|
| Geist | Embutida no `@takumi-rs/core` (napi-rs) |
| JetBrains Mono | Fetch do Google Fonts via CSS API: `https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;500;700;900` (parseia URL dos WOFF2 do response) |
| Pesos necessários | 400 (normal), 500 (medium), 700 (bold), 900 (black) |

### Cache

Response header: `Cache-Control: public, max-age=31536000, immutable` — a imagem OG nunca muda após gerada (dados do roast são imutáveis).

### Tratamento de erros

- `submissionId` ausente ou inválido → ImageResponse fallback genérico com logo devroast + "Code Review Roast"
- Falha ao buscar dados (404) → fallback genérico, status 200 (crawlers ignoram 4xx/5xx)
- Falha ao carregar fonte → renderizar sem a fonte (Takumi usa fallback interno)
- Timeout na renderização → capturar e retornar fallback

## Dependências novas

| Pacote | Motivo |
|--------|--------|
| `takumi-js` | Renderização de imagens OG (Rust → napi-rs) |
| `@takumi-rs/core` | Core nativo (napi-rs, instalado como peer dependency) |

## Riscos e considerações

1. **Tamanho do bundle:** `@takumi-rs/core` é um binário nativo Rust (~15-20MB). Instalado apenas em server/CI, nunca no client. Sem impacto em bundle do navegador.
2. **Tempo de resposta:** Primeira chamada pode ser mais lenta (carregamento do binário nativo + fetch da fonte). Chamadas subsequentes são rápidas com cache do Node.js. Mitigação: cache agressivo (`immutable`) e possível warm-up.
3. **Fonte JetBrains Mono:** Se o Google Fonts estiver inacessível, a imagem renderiza sem a fonte. Mitigação: considerar bundle da fonte no projeto se for um problema recorrente.
4. **Erro silencioso para crawlers:** Crawlers de redes sociais (Twitter, Discord, Telegram) não exibem erro se a imagem falha — apenas mostram um link sem preview. Mitigação: fallback sempre retorna 200 com imagem genérica.
5. **Runtime:** O Takumi nativo (napi-rs) requer Node.js runtime. Não funciona no Edge Runtime. A rota `/api/og` deve usar o runtime Node.js padrão do Next.js.
